A personal portfolio website.

## Project Overview

This is a static personal website built with HTML, CSS, and JavaScript. 

## Features

- Responsive one-page portfolio layout
- About, Experience, Skills, Projects, and Contact sections
- GitHub and LinkedIn profile links
- Project cards for selected GitHub repositories
- Light/dark theme toggle
- Project filtering using JavaScript
- Deployed using GitHub Pages

## Tech Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages
